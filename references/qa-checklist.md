# 自检清单（脚本 + 人工）

渲染完必须过两道：**机器测得的 3 项** 和 **人眼看的 5 条**。任一条不过就改坐标重出，
不要"看着差不多"就交付。

---

## A. 机器检查（`c.save()` 自动跑，或 `c.report()`）

```
QA: PASS
```

`QA: NEEDS FIX` 会打印三块内容：

| 输出 | 含义 | 修法 |
|---|---|---|
| `overlapping text pairs (N)` | 两段文字的包围盒相交，列出字符转义后的前 38 字与相交面积 | 挪 0.1–0.3 inch；拆行；缩字号；缩短文本 |
| `text outside canvas` | 文字跑出画布 | 调 x/y，或把画布尺寸调大（`Canvas(w=16.4)`） |
| `missing glyphs (CJK face cannot render)` | 字体没有该字形，渲染成 □ | 用 ASCII 写法替换（见下表） |

**常见缺字替换表**

| 原字符 | 替代 |
|---|---|
| `₁ ₂ ₃ ₖ ₙ ₍ ₎` | `G1 G2 G3 Nk n ( )` |
| `⚠` | `注意：` |
| `Σ ∑` | `sum` / `Σ` 仅在纯英文串里用（先测） |
| `∘`（函数复合） | `·` |
| `̂`（组合帽，如 X̂） | `X_hat` |
| `→ ← ↑ ↓` | 可用（YaHei 有），但 `⟶`、`⇒` 不行 |
| `≥ ≤ ≠` | 可用 |

判定优先级：**缺字 > 重叠 > 越界**。缺字会让读者看到方框，最致命的先修。

## B. 人眼检查（`read_image` 看，5 条）

- [ ] **一眼读得出输入→输出**：不看正文也知道这张图在讲什么。
- [ ] **标题不压内容**：`box` 标题占框顶约 0.28 inch，内容首行要在 `y+h-0.52` 以下。
- [ ] **颜色语义唯一**：同一颜色只代表一件事；同组数据同色，跨组换色不换形状。
- [ ] **没有大片空白**：底部或侧边的空档要么填"为什么"一句话，要么填约束/口径。
- [ ] **缩写首次出现写全**：`LCC（最大连通片）`、`COO（坐标格式）`。

另外两条针对"解释"是否到位（不达标就补，不是重画）：

- [ ] 图上至少有一个**具体数字**（shape / 索引 / 计数 / 阈值），而不是只有定性描述。
- [ ] 图上有且只有**一句"为什么"**，指出这一步存在的理由。
